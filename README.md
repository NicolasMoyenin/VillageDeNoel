# Village du Père Noël

Application Java de simulation d'un village du Père Noël, réalisée dans le cadre d'un TP de programmation orientée objet.

## Structure du projet

Le projet contient uniquement les classes et interfaces nécessaires à la modélisation du village (personnages, travailleurs, visiteurs, etc.)
